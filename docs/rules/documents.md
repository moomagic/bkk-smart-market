# เอกสารที่ต้องใช้

> ระเบียบตัวอย่างสำหรับ prototype ไม่ใช่ระเบียบจริงของ กทม.

## เอกสารที่ต้องใช้ในการยื่นคำขอ
<!-- keywords: เอกสาร, ใช้อะไร, ต้องเตรียม, บัตรประชาชน, หลักฐาน, ต้องมีอะไร, เตรียมอะไร -->
1. บัตรประจำตัวประชาชน และเบอร์โทรศัพท์ที่ติดต่อได้
2. ยื่นในพื้นที่อาหาร: ใบรับรองการอบรมสุขาภิบาลอาหาร
3. กลุ่มเปราะบาง: หลักฐานตามกลุ่ม เช่น บัตรผู้สูงอายุ หรือบัตรประจำตัวคนพิการ

## ใบรับรองการอบรมสุขาภิบาลอาหาร
<!-- keywords: สุขาภิบาล, อบรม, ใบรับรอง, อาหาร, เครื่องดื่ม -->
ผู้ค้าที่ยื่นในพื้นที่อาหารต้องผ่านการอบรมสุขาภิบาลอาหารก่อนวันตรวจสิทธิ
ยังไม่ผ่านอบรม = ไม่ผ่านการตรวจสิทธิในพื้นที่อาหาร (ยื่นพื้นที่ทั่วไปได้)
สอบถามรอบอบรมได้ที่สำนักงานเขตบางพลัด

## หลักฐานกลุ่มเปราะบาง
<!-- keywords: เปราะบาง, ผู้สูงอายุ, ผู้พิการ, คนพิการ, หลักฐานกลุ่ม -->
กลุ่มเปราะบาง เช่น ผู้สูงอายุ หรือผู้พิการ ต้องแสดงหลักฐานตามกลุ่ม
ระบบบันทึกเพียงว่าอยู่กลุ่มเปราะบาง และเก็บข้อมูลส่วนบุคคลเท่าที่จำเป็นตาม PDPA
